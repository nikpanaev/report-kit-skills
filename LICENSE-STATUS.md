# Текущая среда v3 — NumPy исключён

NumPy, его OpenBLAS/libquadmath и дополнительная DLL msvcp140 из NumPy в новую среду не входят. Вопросы их распространения относятся к исторической среде v2, а не к составу v3. Это не переписывает прошлую проверку и не изменяет установленные скиллы.

Windows Python3.12.15 по-прежнему содержит Microsoft Distributable Code. Его исходный python/LICENSE.txt сохранён без изменений, включая Additional Conditions for this Windows binary build. [Точный текст CPython3.12.15](https://github.com/python/cpython/blob/v3.12.15/PC/crtlicense.txt) описывает дальнейшее распространение с условиями; [сборщик Astral20261013](https://github.com/astral-sh/python-build-standalone/blob/20261013/cpython-windows/build.py) использует штатный PC/layout. Поэтому общая статья о Visual Studio сама по себе не доказывает запрет дальнейшей поставки этой сборки или необходимость Visual Studio сотруднику.

Перед внешней передачей остаётся подтвердить применимость разрешения именно к выбранному архиву Astral и порядок согласия получателя с условиями Microsoft. Сохранение уведомлений и инструкции согласия подготовлены; независимого юридического принятия и настоящей установки не было. Лицензия установщика Microsoft Runtime, дающая установку/использование, не подставляется вместо основания дальнейшего распространения DLL. Замена способа скачивания или выбор другой открытой обёртки не снимают автоматически условия вложенных компонентов.

Собственный код остаётся MIT. Все прочие уведомления Python/Pillow/Playwright/Node сохраняются. Публикация и установка не разрешены этим срезом.
