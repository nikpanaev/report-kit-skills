# Инструменты Report Kit

Здесь находятся инструменты для получения статистики и снимков публикаций из LiveDune и социальных сетей.

**Если вы хотите делать отчёты, начните с [Report Kit](https://github.com/nikpanaev/report-kit-agent).** Основной помощник сам выберет нужные инструменты и объяснит настройку. Устанавливать этот репозиторий отдельно и выбирать версии не требуется.

## Какие источники есть

- LiveDune.
- VK: публикации, комментарии, сообщения сообщества и истории.
- Telegram и MAX: публикации и комментарии.
- Instagram, Threads и TikTok: публикации.

Подключаются только нужные для задачи источники. Доступ к аккаунту сотрудник предоставляет отдельно; чужие ключи и сессии в поставку не входят.

## Состояние тестовой версии

Выполнены локальные тесты и проверены файлы поставки. Часть сценариев и готовая среда проверены на macOS. Работа с аккаунтами, первая настройка у сотрудника и работа в Windows ещё требуют проверки. [Результаты](EVIDENCE-INDEX.md).

Подготовлены варианты среды для Windows 11 и новее, x64, и macOS 14 и новее на Apple Silicon. Другие системы этой поставкой пока не поддерживаются. Python и библиотеки вручную устанавливать не нужно: настройку ведёт основной помощник.

## Для сопровождающего

[VERSION](VERSION) содержит текущий номер. Состав инструментов и их зависимости описаны в [каталоге](capabilities.json). Основной агент закрепляет точную совместимую версию в своём dependencies.json; произвольное содержимое main для установки не используется.

[Сопровождение](skills/_shared/MAINTENANCE.md) · [Данные и доступы](skills/_shared/DATA-BOUNDARY.md) · [Среда запуска](skills/_shared/RUNTIME.md) · [Архив поддержки](skills/_shared/SUPPORT.md)

Обновления сохраняют клиентские правила и данные. Действующие клиентские агенты и установленные инструменты не меняются одной публикацией новой версии. Инструкции обновляются вместе с изменениями, в рамках той же задачи.

Собственный код — под [лицензией MIT](LICENSE). Сторонние компоненты сохраняют свои условия: [лицензии](LICENSE-STATUS.md), [зависимости](THIRD-PARTY-DEPENDENCIES.md). Принятое основание передачи Windows-компонентов относится к тестовому выпуску; отдельного юридического заключения нет.
