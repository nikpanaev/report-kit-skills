# Среда источников Report Kit

На Windows выбранный агент показывает условия компонентов Microsoft и сохраняет прямое согласие в private workspace. Скилл получает команду только через runtime.execution_plan с подтверждением текущего текста; не запускать Python напрямую в обход остановки. Исходные лицензии входят в неизменённый core; NumPy отсутствует. Этот порядок подготовлен, настоящее прохождение сотрудником ещё не проверено.

Совпадения runtime_id недостаточно: выбранный агент сверяет версии всех слоёв с своим рецептом до пробного запуска/исполнения и при обновлении. Скиллы не исправляют версии самостоятельно и не обходят остановку этой проверки.

Сотрудник не устанавливает Python/библиотеки/Node вручную. Setup выбранного report-kit-agent готовит exact private runtime, проверяет нужные capability modules и выдаёт argv через runtime.execution_plan. Не искать произвольный interpreter или менять user/global environment. Старые low-level ошибки о pip являются диагностикой для агента, не заданием сотруднику.

При выбранном проверенном Chrome shared browser_zoom принимает REPORT_KIT_BROWSER_CHANNEL=chrome; unset сохраняет прежний Chromium. Stories принимает --channel; messages при --profile использует Chrome без параметра --channel. Не менять масштаб, светлую тему, retries, FIFO, capture/video/privacy guards. Если скиллу нужен Playwright Chromium, агент сначала предлагает подготовку и получает согласие. Запрет организации не обходить другим каналом. Отдельный профиль, без импорта повседневного профиля Chrome.

Версии runtime проверяются вместе с выбранной парой source/agent и всеми клиентами. Новый runtime не активировать во время отчёта; предыдущий сохранять для возврата и fallback. Данные/сессии/ключи находятся отдельно. Windows подтверждается только настоящей проверкой сотрудником; наличие wheels и Node asset не поддержка устройства.

Первый runtime test profile: Windows11+ x64/macOS14+ arm64; фактическую ОС проверяет coordinator до исполнения. Наличие wheel для другой ОС не расширяет этот профиль.

Обработка кадров и склейка MAX в текущем переносимом комплекте требуют Pillow. NumPy не нужен и не поставляется; не устанавливать его по старой диагностике или исторической инструкции. Установленные личные скиллы этим изменением не обновляются.
