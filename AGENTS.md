# Development instructions

Сначала прочитать и соблюдать `../AGENTS.md`, если он существует. В отдельном clone использовать принятый [Universal App Development Framework v3.4.0](https://github.com/nikpanaev/universal-app-development-framework/blob/v3.4.0/FRAMEWORK.md), commit `63f4faee40598bd3d6e75d49777fa00982c20811`; main не authority.

Scope: только этот репозиторий и явно порученные source exports. Не менять installed skills, existing client agents, credentials, browser profiles или глобальный Codex config. Нет полномочия на remote, push, публикацию, установку плагинов и внешние записи. Общие правила отчётной работы будут в package skill references, не в процессе разработки.

Перед material work читать README и CHANGE-SPEC.md. VERSION — единственный источник development-version. Local reversible checks разрешены; результаты и ограничения сохранять в EVIDENCE-INDEX.md. До проверки лицензий и чистого устройства не объявлять публичный выпуск или end-to-end готовность.
