# Report Kit — источники

При разработке или сопровождении пакета соблюдай [правило актуальности документации](skills/_shared/MAINTENANCE.md#документация-при-изменении-скилла): обновляй затронутые инструкции вместе с изменением, до завершения задачи. Это не разрешение править пакет во время клиентского отчёта.

Выбери скилл по платформе и типу материала в [каталоге](capabilities.json), прочитай его полный SKILL.md и применимые ссылки. Публикация, комментарии и личная переписка — разные задачи; не заменяй один тип другим. Наличие скилла не доказывает доступ к аккаунту, установку или поддержку устройства.

Файлы пакета при использовании не меняются. Сессии, ключи, очереди, browser state и outputs должны находиться во внешнем приватном хранилище. Используй разрешённые подключения сотрудника; чужая авторизация и клиентские данные не поставляются. Секреты не записывай в чат, argv, отчёт или обычный конфигурационный файл.

Перед UI-действием используй единую согласованную очередь по [правилам данных](skills/_shared/DATA-BOUNDARY.md), не создавай конкурирующие store. Не обходи отказ безопасности или доступа. При ошибке сохрани точный обезличенный результат и действуй по [maintenance](skills/_shared/MAINTENANCE.md); разрешение на сообщение и дальнейший запуск проверяй отдельно. Пауза и бюджет сохраняются.

Удаляй только свои ненужные временные файлы после компактных receipts; сохраняй исходники, итоговые файлы и незавершённые материалы восстановления. VERSION и contracts.json описывают выбранный пакет; они не являются разрешением на установку, обновление или live-доступ.

[Сведения для поддержки](skills/_shared/SUPPORT.md) — только local allowlisted events; raw logs не считаются безопасными. Capture/API/queue сохраняют прежний рабочий журнал и правила retries/budget. Не передавать raw exception text, ссылки, IDs, личные пути, session data или содержимое результата в поддержку. По просьбе на архив использовать один collector выбранного report-kit-agent; standalone collector этого пакета поддерживает тот же формат. Никакой автоматической отправки.

Подготовленная среда, выбор Chrome и предложение браузеров Playwright — [runtime](skills/_shared/RUNTIME.md). Не поручать сотруднику ручную установку Python или библиотек.
